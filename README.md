# SolanaSentinel: Autonomous AI Transaction Firewall, DeFi Router & On-Chain Quest Arena

Live Production Deployment: **https://solana-ai.prince.sh**

Built for the **MLH Solana Hackathon** across all prize tracks:
- **Top 3 Overall**: Live Solana Devnet JSON-RPC integration (`https://api.devnet.solana.com`), Ed25519 agent vault derivation, Base58 encoding, and sub-second transaction simulation.
- **AI Track**: Autonomous AI Transaction Firewall and Natural-Language Intent Compiler that turns plain-English requests into verified Solana instructions (`ComputeBudget`, `Jupiter v6 SharedAccountsRoute`, `SPL-Memo`), enforces daily lamport spending limits, blocks unauthorized `SetAuthority` drain attacks before signing, and anchors SHA-256 AI inference provenance hashes on-chain.
- **DeFi Track**: Multi-DEX Smart Order Router comparing Orca Whirlpools, Raydium CLMM, and Meteora DLMM routes alongside instant **Solana Pay** machine-to-machine micropayment URIs (`solana:<recipient>?amount=0.05&reference=...`).
- **Gaming & Best Beginner Hack**: Interactive On-Chain Security & DeFi Quest Arena where developers and players inspect raw Solana instructions, stop phishing transactions, and earn verifiable Devnet achievement badges.

## Quickstart

```bash
# Verify live Solana Devnet RPC telemetry and AI firewall output
npm run verify

# Start the interactive web server on port 4585
npm start
```
